Every text file in this repository is bilingual: English first, then Polish (`# Wersja polska` or a clearly marked Polish part):

Każdy plik tekstowy w tym repozytorium jest dwujęzyczny: najpierw po angielsku, potem po polsku (`# Wersja polska` lub wyraźnie oznaczona część polska):
